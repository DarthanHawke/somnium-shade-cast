Somnium Shade Cast
В этом репо я разрабатываю self-hosted монолитный сервис хранения и потокового воспроизведения собственной коллекции музыки с подключением и деплоем через SSH с помощью desctop/mobile api и системой рекомендации своих треков на основе весов: тегов, теневого профиля, паттернов прослушивания с возможностью скробблинга в Last.FM и управлением собственной коллекцией.
